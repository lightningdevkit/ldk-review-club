## Notes
[BOLT12](https://github.com/lightning/bolts/blob/master/12-offer-encoding.md) introduces offers, which provide a way for nodes to have a static QR code. When another user scans it, they send an `invoice_request` message and receive a unique invoice every time.

[bLIP-52](https://github.com/lightning/blips/blob/master/blip-0052.md) introduces JIT Channel Negotiation which provides a way for clients with no Lightning channels/inbound liquidity to receive payments via an LSP.

This PR adds BOLT12 support to LSPS2 via custom Router implementation.
